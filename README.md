# 太空躲避外星人

一个纯静态的横版躲避小游戏：飞船在星际航道里左右闪避不断下压的外星人，靠「险避」与「脉冲清场」滚连击分数。支持鼠标 / 键盘，也可以用摄像头做手势操作。

## 在线演示

https://space-game-yly.netlify.app

打开后会自动跳转到游戏页面。站点部署在 Netlify 上（HTTPS），因此摄像头与手势可以直接授权使用。

## 本地运行

页面的手势库通过 ES Module 和 `fetch` 加载，`file://` 方式打开会拿不到摄像头，请用本地 HTTP 服务：

```powershell
cd <项目目录>
python -m http.server 8123
```

然后访问 `http://127.0.0.1:8123/space-game/`（也可直接开 `http://127.0.0.1:8123/`，根入口会自动跳转）。

摄像头只在安全上下文可用：`localhost` / `127.0.0.1` 或 HTTPS。用局域网 IP（如 `http://192.168.x.x:8123`）访问时手势不可用，但键鼠仍可正常游玩。

## 操作方式

### 键盘 / 鼠标

| 操作 | 效果 |
| --- | --- |
| `←` `→` 或 `A` `D` | 左右移动飞船 |
| 鼠标在场地内移动 | 飞船跟随鼠标横坐标 |
| `空格` / 点击场地 / 点「脉冲」按钮 | 释放脉冲，清掉周围敌人 |
| `P` | 暂停 / 继续 |
| `Enter` | 在游戏页直接开始 |
| 首页 / 选关 / 结算 | 均可直接点击按钮 |

### 手势（MediaPipe HandLandmarker）

| 手势 | 效果 |
| --- | --- |
| 食指指尖移动 | 控制菜单光标，可隔空点击按钮 |
| 掌指关节横向移动 | 控制飞船左右位置 |
| 握拳（瞬间） | 释放脉冲 |

点游戏页的「手势 · 开」按钮请求摄像头。以下情况会自动降级为键鼠，不会卡在授权环节：

- 用户拒绝授权、设备没有摄像头、浏览器不支持；
- 授权弹窗 12 秒内没有响应（提示「摄像头未响应」）；
- 用 `file://` 打开页面。

降级后状态栏会提示「鼠标/键盘可玩」，随时可以再点按钮重试。窄屏（宽度 ≤640px）会自动隐藏摄像头回看小窗，避免遮挡场地。

## 关卡与计分

- 共 10 关，每关 3 波；每波的速度、出怪节奏和敌人种类都会递进，通关后解锁下一关。
- 敌人四种：普通外星人、体型小速度快的侦察兵、会横向追踪的追踪者、只挡路不计分的炸弹。
- 道具：三档宝箱（+30 / +80 / +150 分）与护盾（抵挡一次撞击）。
- 得分来源：正常躲过、贴脸「险避」（额外加分）、脉冲清场、拾取宝箱。
- 连击：3.6 秒内持续得分累积连击，每 5 连击提升一档倍率，最高 ×5。
- 初始 3 条命，撞击扣 1 条；护盾可抵挡一次。
- 每关最佳分数与解锁进度保存在浏览器 `localStorage`。


## 技术栈

- 原生 HTML / CSS / JavaScript（ES Module），无构建步骤、无框架。
- Canvas 2D 绘制飞船、敌人、粒子与冲击波；`requestAnimationFrame` 驱动主循环。
- MediaPipe Tasks Vision `HandLandmarker` 做手部关键点识别，库与模型都放在 `vendor/` 内，不依赖外部 CDN。
- Web Audio 程序化合成音效（爆炸、拾取、脉冲等），无需音频文件。
- `localStorage` 记录关卡解锁与每关最佳分。

推荐使用较新版本的 Chrome / Edge。
